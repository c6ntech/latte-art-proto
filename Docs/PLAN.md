## 每個版本的固定節奏（latte-loop 技能）

改一個東西 → 語法檢查（hook 自動）→ sim 不壞（之後加量測與核准截圖比對）→ 蓋版本 → 推送 → `tools/wait_for.py --url` 確認上線 → 回覆你版本號與要測什麼。壞版本不推給你。
