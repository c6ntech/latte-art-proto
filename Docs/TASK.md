# 拉花遊戲（暫名）— 任務書

> v2，2026-10-10。v1 是 2026-10-08 owner 貼的原始需求；v2 併入 owner 在 10-08 與 10-09 的兩次修正（D001、D002）。
> 這份是 WHAT；`CLAUDE.md` 是 HOW。新 session 不要整份重讀，看 `Docs/state/STATE.md` 指到的章節。

## 0. 一句話

**手機就是杯子。** 奶泡鋼杯和手固定在畫面上方倒牛奶；杯子很難端穩、會自己慢慢飄，玩家用傾斜手機把杯子接回奶流底下，讓牛奶一直落在杯面上方的甜蜜點。倒完才看到成品；接得好就是一朵清楚的拉花，接不好那一段就糊掉。

成功標準（第一階段）：owner 自己倒十次之後還想倒第十一次。

## 1. 第一階段只做這件事

接好一杯拉花。不做關卡、不做廣告、不做造型。一套動作：葉子（rosetta，D011；原本是鬱金香）。

## 2. 玩法（已定案）

1. 打奶泡：按住按鈕，有機器聲與奶泡上升；放開即完成，必定成功。儀式，不是考驗。
2. 按開始後，鋼杯由電腦操作自動走完一套拉花動作。**鋼杯與手固定在原地，不左右跳動**（D001）。**一次倒完不中斷**：從開始倒到圖案完成，奶流不停，圖案在倒的過程中於杯子中央成形（D010）。預設圖案是**葉子（rosetta）**（D011），手腕小幅搖晃、拉穿成葉。
3. 玩家是拿杯子的手。傾斜對應杯子在桌面上的位置（角度對應位置，不是速度）。**杯子會自己慢慢飄走**，玩家要把它接回來（D001）。
4. 傾斜超過門檻 → 翻倒，整杯失敗。
5. 判定：倒的全程中，奶流落在甜蜜點內的時間比例 ≥ 80% 成功。落在外面的時段，對應的圖案真的糊掉（由模擬算出，不是事後蓋模糊）。
6. 圖案倒的過程不預告，倒完完整呈現。無限重來，不用等。
7. 第一章顯示淡淡的甜蜜點目標區，之後章節逐漸不顯示；可開關。
8. 鋼杯動作看得見、有節奏；開始移動前有短暫預備動作，玩家能預判。
9. **要順暢、簡單、過得了關**（D002）：有在扶就該過；完全不管才會失敗。圖案要自然出現，不是靠運氣。

## 4. 輸入

- 只支援手機陀螺儀（`deviceorientation`），不做觸控，不做桌機版。桌機只有開發用的模擬。
- 開局「把手機拿平」歸零。
- iPhone Safari 要在使用者點擊內呼叫 `DeviceOrientationEvent.requestPermission()`，網址要 https。

## 5. 視覺與物理

- 咖啡深色底、牛奶白色；倒下去要像真的拉花：擴散、推開、留下清楚的邊。這是核心，時間優先投這裡。
- 畫面固定在杯子與鋼杯；要畫拿鋼杯的手。一個杯子、一個鋼杯、一隻手、一個按鈕。
- **呈現（D007）**：低面數稜角模型 + 低解析度像素貼圖 + 柔和真實光影，接近俯視的 2.5D。規則見 `Docs/STYLE_BIBLE.md`，參考圖在 `Docs/concepts/approved/style/`。拉花本身也是像素（約 72 格）。
- 揭曉先做最陽春版，但糊掉必須是真的。

| 現實 | 處理 | 狀態 |

## 7. 之後的方向（架構先留位置）

- 多套動作（愛心、葉子、鬱金香、天鵝）：一套 = 一個資料檔。
- 六個難度參數：流速、重力、容器形狀、液體黏度、杯子干擾、鋼杯干擾（`LEVEL`）。
- 六個章節：正常咖啡廳、奇怪容器、奇怪液體、環境干擾、外太空、荒謬現場。
- 畫面永遠固定在杯子與鋼杯，背景可換。關卡轉場由畫面外進來的「客人的手」完成。
- 造型三類：咖啡機、鋼杯、手套；看廣告抽取；未取得顯示黑剪影。
- 廣告與收費之後再定。

## 8. 不做

多人、帳號、伺服器、桌機版、觸控玩法、第一階段的任何美術精修。
